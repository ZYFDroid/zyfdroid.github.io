卡片堆叠收纳 - 游戏说明

🎮 基础玩法

游戏目标

通过策略性地移动和收纳卡片，获得尽可能高的分数。

游戏界面

  • 顶部区域：3个收纳框，每个框需要收集特定颜色的卡片
  • 中间区域：7个堆叠位置，用于存放和整理卡片
  • 底部区域：操作按钮区域

操作方式

  1. 选择卡片：点击任意堆叠，自动选中顶部所有同色卡片
  2. 移动卡片：选中卡片后，点击另一个堆叠进行移动
  3. 收纳卡片：选中卡片后，点击对应颜色的收纳框
  4. 移动规则：只能移动到空堆叠或顶部颜色相同的堆叠

🎯 按钮说明

回收按钮

  • 功能：清空指定堆叠的所有卡片
  • 使用方法：点击回收按钮，然后点击需要回收的列。

添加卡片按钮

  • 功能：为每个堆叠添加3张随机卡片
  • 使用限制：无限制，可随时使用
  • 特殊机制：
    • 20%概率生成连续同色卡片（2-3张）
    • 50%概率生成收纳框所需颜色
    • 每个堆叠上限50张卡片

吸纳按钮

  • 功能：一键吸纳所有堆叠中指定颜色的卡片到选中的收纳框
  • 使用方法：点击吸纳按钮，然后点击一个收纳筐

💰 得分说明

基础得分

  • 完成收纳：每个收纳框达到8张卡片获得基础50分

手动移动奖励

  • 翻倍奖励：从0直接完成收纳框，得分翻倍（100分）
  • 超额奖励：超过8张卡片，每多1张额外加10分
  • 示例：
    • 从0到8张：100分
    • 从3到10张：50 + (10-8)×10 = 70分
    • 从5到12张：50 + (12-8)×10 = 90分

吸纳道具得分

  • 固定得分：使用吸纳道具完成收纳，固定获得50分
  • 无额外奖励：不享受翻倍和超额奖励

🎁 道具说明

道具获取

  • 初始数量：收纳和吸纳道具各5次
  • 增加机制：每获得500分，两种道具各增加5次
  • 上限限制：每种道具最多15次

道具策略

  • 回收道具：适合紧急情况，快速清理混乱堆叠
  • 吸纳道具：高效完成收集，但得分较低
  • 权衡选择：手动操作得分更高，但需要更多策略思考

🏆 游戏技巧

高分策略

  1. 积累卡片：尽量在收纳框中积累更多卡片再完成
  2. 从零开始：清空收纳框后重新收集可获得翻倍奖励
  3. 合理布局：将相同颜色的卡片集中堆叠
  4. 道具使用：在关键时刻使用道具，避免浪费

注意事项

  • 每个堆叠最多容纳50张卡片
  • 超过限制的移动会失败
  • 游戏进度自动保存，可随时继续
  • 合理规划收纳框颜色，优先收集堆叠中数量多的颜色
